# Omar Aliyev SOC Analyst Portfolio

Personal portfolio website for Omar Aliyev, a Computer Science / Cyber Security student at the University of Wollongong in Dubai targeting junior SOC Analyst, threat detection, and incident response roles.

## Files

- `index.html` - main website page
- `styles.css` - responsive styling
- `server.py` - optional local Python server
- `assets/omar-aliyev-headshot.jpg` - optimized profile photo
- `assets/cisco-introduction-to-cybersecurity.png` - Cisco badge image
- `assets/Omar_Aliyev_Resume_Updated.pdf` - downloadable resume

## Run Locally

```bash
python3 server.py
```

Then open:

```text
http://127.0.0.1:8765
```

You can also open `index.html` directly in a browser.

## Deploy With GitHub Pages

1. Create a new public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub, go to `Settings > Pages`.
4. Set source to `Deploy from a branch`.
5. Select the `main` branch and `/root`.
6. Save and wait for GitHub Pages to publish the site.

## Notes

The site is intentionally static and simple so it works cleanly on GitHub Pages. The Python server is only for local preview.
